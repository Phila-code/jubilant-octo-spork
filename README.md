# Savoury Bites
A modern and responsive restaurant website created for Savoury Bites, a fictional restaurant focused on delicious food, welcoming service and simple online reservation experience.
The website was built as a front-end web development project using HTML, CSS and Java Script.

# About the Project
Savoury Bites is a multi-page restaurant website designed to give visitors an easy way to :
* Explore the restaurant
* View the food menu
* Discover current specials and promotions
* Make a reservation
* Find restaurant contact information
* Switch between light and dark mode

The project focuses on creating a clean, attractive and user-friendly restaurant experience.

This project was developed for educational purpose as part of my school coursework.

# Features
🏠 Home Page
* Restaurant introduction
* Hero section
* Welcome message
* Navigation to the menu
* Restaurant information
* Reservation button

🍽️ Menu Page

The menu includes different food categories such as:

Starters
* Garlic Bread
* Chicken Wings
*  Greek Salad

Main Meals 
* Grilled Steak
* Chicken Alfredo
* Beef Burger

Each meal includes a description and price.

🔥 Specials Page

Display featured restaurant promotions, including:

* Grilled Steak Combo
* Chicken Alfredo Delight
* MilkTart Dessert
* Special offers and promotional tags
* Food images

 📅 Reservation / Contact Page

 Visitors can submit a reservation from containing:

 * Full name
 * Email address
 * Reservation date
 * Reservation time
 * Number of guest

The page also provides:

* Restaurant address
* Phone number
* Email address
* Opening hours

🌙 Dark Mode 

The website includes a dark-mode toggle that allows users to switch the website's appearance.
The selected mode is saved using localStorage, so the preference can reamin when user returns to the website.

📱 Responsive Design

The website uses responsive CSS techniques such as:

* Flexbox
* CSS Grid
* Flexible layouts
* Responsive navigation and content sections

This allows the website to adapt to different screen sizes.

2. Open the project

3. Launch the website
